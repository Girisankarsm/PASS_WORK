## 3. Unsuitable AI Suggestions Identified & Corrected

### Unsuitable Suggestion 1: Incomplete Dirichlet Boundary Condition
- **AI Suggestion**: The initial code generated by the LLM for the thermal FEA Dirichlet condition only zeroed the column in $K$ and subtracted $K[i][n] \cdot T_L$ from $F[i]$, but left the non-diagonal elements of row $n$ intact ($K[n][n-1] = -k A / h$).
- **Identified Defect**: When the linear solver executed Gaussian elimination, the equation for node $n$ still had coupling to node $n-1$, resulting in $T(L) = 20.73^\circ\text{C}$ instead of the prescribed boundary value $20.00^\circ\text{C}$.
- **Candidate Correction**: Identified during automated test failure. Explicitly updated the algorithm to zero all off-diagonal entries in both row $n$ and column $n$, setting $K[n][n] = 1.0$ and $F[n] = T_L$. Verified exact Dirichlet satisfaction in test suite (`BC: T(L)=20°C` PASS).

### Unsuitable Suggestion 2: CSV Parser Failure on Leading Header Comments
- **AI Suggestion**: The suggested CSV parser called `std::getline(ss, line)` once and immediately passed the first line into column header tokenization.
- **Identified Defect**: Sample CSV datasets (such as `data/csv/temperature_rod.csv`) commonly contain metadata header comments starting with `#`. The parser failed with HTTP 400 Bad Request on authentic scientific data files.
- **Candidate Correction**: Replaced fragile single-line read with a loop skipping whitespace and `#` comment lines before parsing column names.
